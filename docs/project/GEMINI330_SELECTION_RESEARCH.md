# Gemini 330 系列相机联网选型报告

> 调研日期：2026-09-30  
> 目标：为“四台固定 3D 相机扫描静止车辆，并将现场融合点云匹配到已保存车辆模板，再迁移喷涂机械臂路径”选择硬件型号。  
> 结论：**首选 Gemini 336L，Gemini 335L 作为备选；335/336 不作为当前四角固定阵列的首选。**

## 1. 最终建议

建议先采购或借测 **4 台 Gemini 336L**，按车辆四角高位固定安装，距离车身约 2-4 m。采集采用逐台顺序触发：一台相机完成深度采集后，再触发下一台。所有相机通过 ChArUco 标定到同一个工位坐标系，再进行点云融合、车辆模板配准和喷涂路径迁移。

Gemini 335L 保留为备选，适用于以下情况：

- 336L 供货周期或成本明显不利；
- 同一工位 A/B 测试证明 335L 在车漆、玻璃、轮胎和高反光区域的有效深度率已经满足误差预算；
- 需要保留可见光加 NIR-Pass 的输出特性，而不是 IR-Pass 深度滤光方案。

这不是“336L 的标称空间精度远高于 335L”的结论。两者的 L 型号几何规格接近，336L 的主要采购理由是**复杂光照和反光车身上的深度稳定性**。

## 2. 项目需求与选型约束

当前业务链路不是对车漆做微米级逆向建模，而是：

```text
四路 RGB-D 采集
  -> ChArUco 外参统一到工位坐标
  -> 点云融合
  -> 与系统保存的车辆模板配准
  -> 得到现场车辆位姿
  -> 迁移模板坐标系中的喷涂 TCP 路径
```

因此最重要的指标依次是：

1. 2-4 m 距离内的深度稳定性和有效深度覆盖率；
2. 车漆、玻璃、黑色轮胎、金属高光面等材料上的鲁棒性；
3. 四相机固定阵列的视场覆盖和外参重复性；
4. 软件触发、硬件触发和多机时间戳能力；
5. USB 带宽、供电、散热和长时间运行稳定性；
6. IP 防护、安装结构和现场维护成本。

## 3. 候选型号对比

下表结合用户提供的正式《Gemini 330 Series Datasheet V1.6》和奥比中光当前产品页整理。具体采购仍以实际出货版本和 SDK 支持为准。

| 型号 | 基线 | 理想工作距离 | 官方关键能力 | 对本项目的判断 |
| --- | ---: | --- | --- | --- |
| Gemini 335 | 50 mm | 约 0.3-3 m | 标准 330 系列，IP5X | 适合近距离验证，不适合作为车辆四角阵列首选 |
| Gemini 336 | 50 mm | 约 0.3-3 m | 具备可见光过滤/主动红外增强方向 | 环境适应性有优势，但工作距离和 L 型号精度余量较小 |
| Gemini 335L | 95 mm | 约 0.25-6 m | IP65、Visible+NIR-Pass、支持触发和多机同步 | 可用，且是当前软件仿真基线；作为备选 |
| **Gemini 336L** | **95 mm** | **约 0.25-6 m** | **IP65、IR-Pass、支持触发和多机同步** | **首选** |

### 336L 官方规格摘要

- 深度范围：约 0.17-20 m 以上；最佳工作距离 0.25-6 m；理论最大深度范围可达 65 m。
- 深度：最高 1280×800@30 fps；深度视场角 H90° × V65°。
- RGB：最高 1280×800@60 fps；RGB 视场角 H94° × V68°。
- 空间相对精度：≤0.8%@2 m（1280×800，81% ROI）；≤1.6%@4 m（1280×800，64% ROI）。
- 接口与输出：USB 3.0 Type-C，输出点云、深度图、IR 和 RGB；支持 IMU、触发和 Orbbec SDK。
- 功耗和环境：平均功耗小于 3 W；工作温度约 -10 至 50°C；室内/室外，5%-90%RH 非冷凝。
- 外形和安装：约 124×29×27.7 mm、135 g，底部 1/4-20UNC、背部 2×M4。

注意：0.17-20 m 是可测范围，不等于 20 m 仍保持车辆模板匹配所需的精度。车辆阵列应把主要车身区域放在 0.25-6 m 内，并按实际安装距离重新核算误差。

## 4. 联网资料带来的关键判断

### 4.1 336L 与 335L 的差异确实集中在红外成像

奥比中光 336L 官方产品页说明，336L 在 335L 的长基线设计和深度性能基础上增加 IR-Pass，过滤可见光，以提升主动红外成像在反光和复杂光照条件下的稳定性。官方举例包括室内反光表面产生眩光的场景，并将 336L 用于 3D reconstruction / 3D body scanning。

车辆不是均匀漫反射目标：车漆、玻璃、轮胎、镀铬装饰和湿润表面会同时出现高光、低纹理和暗部。336L 的滤光设计与本项目的误差来源直接相关，因此其优势比“多一个同步接口”更值得优先验证。

### 4.2 两者的几何规格接近，不能夸大 336L 的数值精度优势

官方 335L 页面同样给出 95 mm 基线、0.25-6 m 最佳范围、90°×65° 深度视场和最高 1280×800@30 fps。336L 的主要变化是 IR-Pass，而不是把车辆位姿误差自动降低一个数量级。

此外，官方页面的精度指标带有 ROI 条件：336L 在 2 m 使用 81% ROI、4 m 使用 64% ROI；335L 页面给出的 ROI 条件为 2 m 的 90%×90% 和 4 m 的 80%×80%。这意味着：

- 336L 的中心区域深度稳定性值得优先测试；
- 不能只用中心平面测试结果推断车身边缘、车门边缘和车顶边缘；
- A/B 测试必须记录整车有效深度率和边缘断裂，而不是只记录一个平面 RMSE。

### 4.3 多机同步能力存在，但静止车辆不应默认同时发射

奥比中光官方多设备同步示例将设备分为 Primary 和 Secondary，支持通过同步信号协调多台设备；官方 SDK 示例还覆盖 USB、网络和 GMSL 设备，并说明 Gemini 330 系列可通过 8-pin 端口实现多机同步。

这证明 336L/335L 的同步能力可用于工程扩展，但不改变当前采集策略：车辆静止时，四台主动红外相机同时工作可能产生互扰，优先采用软件顺序触发或硬件触发的分时序列。只有在车辆、转台或机械臂运动时，才需要把同步时间戳和运动补偿提到更高优先级。

### 4.4 连接方式是四相机方案的实际风险

336L 和 335L 官方产品页都列出 USB 3.0 Type-C 作为数据和供电接口，平均功耗约 3 W。当前没有依据把 336L 当作 PoE 相机使用，因此四台相机部署不能直接按“一个 PoE 交换机解决全部问题”设计。

四相机正式部署前必须验证：

- 主机是否有足够的独立 USB 3.x 控制器带宽；
- 有源 USB 3 集线器、线缆长度和供电是否导致丢帧或重连；
- 四路深度流在 1280×800@30 fps 下的总吞吐；
- 顺序触发时设备枚举顺序、时间戳和帧号是否稳定；
- 连续运行 1-2 小时后的温升、断流和重新连接时间。

## 5. 为什么不是 Gemini 335L 首选

335L 不是不能用，甚至它是当前仓库仿真基线，已有参数文件、外观模型和网页结果。但将它作为首选的唯一理由如果是“有同步闪光灯线”，就不成立：

1. 当前目标是静止车辆模板匹配，不依赖四台相机同一时刻曝光；
2. 顺序采集可以降低主动红外互扰，同步接口不再是核心指标；
3. 336L 与 335L 的长基线和工作距离接近，但 336L 针对可见光和反光场景增加了 IR-Pass；
4. 335L 只有在价格、供货、兼容性或 A/B 测试结果明显更有利时，才应降为实际采购备选。

## 6. 推荐的四相机工程方案

```text
Gemini 336L × 4
  -> USB 3.x 工业主机/有源集线器（先做带宽实测）
  -> Orbbec SDK 顺序触发
  -> 每台相机独立采集并记录设备序列号、帧号、时间戳
  -> ChArUco 外参标定到工位世界坐标
  -> 点云滤波、融合和覆盖率检查
  -> FPFH/RANSAC 粗配准 + ICP 精配准
  -> 输出车辆位姿和喷涂 TCP 路径迁移结果
```

安装建议：

- 四台相机优先布置在车辆四角的高位斜视位置，不要把四个视线都压在车顶中心；
- 让车身主要区域落在 2-4 m 深度范围内，保留车顶、侧面和车轮的重叠区域；
- ChArUco 标定板应在相机视场内提供足够角点，标定时记录每台设备的内参和畸变，而不是只使用规格书 FOV；
- 先执行一台相机的深度采集，再切换到下一台；如 SDK 无法可靠关闭主动发射，需由厂商确认分时触发配置。

## 7. 采购前 A/B 验证门槛

用同一车辆、同一支架、同一距离和同一照明条件比较 336L 与 335L，至少覆盖 2 m、3 m、4 m 三个距离，并分别统计：

| 测试项 | 通过标准建议 |
| --- | --- |
| 车漆/玻璃/轮胎/高光面的有效深度率 | 分区域统计，不只看整车平均值；关键区域不得持续出现大片空洞 |
| 平面和边缘深度误差 | 用标定平面和已知尺寸边缘分别评估，记录 RMSE、P95 和最大误差 |
| 四相机融合重影 | 固定场景重复采集后，重叠区域不得出现明显双层边缘 |
| 模板位姿重复性 | 多次采集的平移、旋转标准差满足喷涂路径误差预算 |
| 路径迁移误差 | 在车辆模板上的关键 TCP 点做独立复核 |
| 顺序触发稳定性 | 无丢帧、无错配帧号，四台设备均能按序完成采集 |
| USB 和热稳定性 | 连续 1-2 小时无断流、重连和明显温升导致的质量下降 |
| 标定维护成本 | 重新安装后 ChArUco 外参可重复恢复，并有质量报告 |

采购决策规则：

- 若 336L 在反光/暗部有效深度率、融合重影和模板位姿重复性上明显优于 335L，采购 336L；
- 若两者差异不明显，而 335L 价格或供货优势显著，则采购 335L，并保留后续 336L 升级空间；
- 若两者都无法满足边缘区域误差预算，问题不是简单更换型号，应先调整相机数量、安装距离、遮挡处理、触发策略和标定质量。

## 8. 结论和边界

**当前推荐：Gemini 336L × 4。**它最适合本项目的原因是长基线工作距离、防护等级、触发/多机扩展能力，以及针对反光和复杂可见光环境的 IR-Pass 设计。

但 336L 不是“无需标定即可得到精模”的保证。官方精度数字有距离和 ROI 条件，实际车辆边缘、玻璃和黑色轮胎仍必须通过 A/B 采集验证。仓库现有 335L 仿真参数继续保留，用于算法回归；真实部署时应替换为每台 336L 从 SDK/设备读取并完成 ChArUco 标定后的内参和外参。

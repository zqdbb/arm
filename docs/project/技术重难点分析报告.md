# 小批量家具自动喷涂机器人（视觉感知 → 拓扑分析 → 喷涂路径规划）技术重难点分析报告

版本：v1.0　编写日期：2026-08-27　适用阶段：预研 / 方案立项

---

## 0. 本报告的范围界定

### 0.1 系统构型（Baseline，已由前期研究收敛）

| 要素 | 选型 |
|---|---|
| 机械臂 | 6 轴工业/协作臂，末端法兰装 RealSense D4xx（Eye-in-Hand） |
| 变位机 | 单轴回转工作台（转台），承载家具，360° 旋转 |
| 采集策略 | 机械臂在若干**固定高度 + 固定俯/仰角姿态**驻留，靠转台旋转获取多视角（半结构化扫描），替代 NBV 动态探索 |
| 工件 | 小批量家具（小桌、椅、带隔板柜体），**主要功能面为平面**（先验） |
| 软件栈 | ROS 2 + `scan_n_plan_workshop` 框架 / `noether`（面分割 + 刀路规划）/ MoveIt 2 或 Tesseract（运动规划） |

### 0.2 本阶段 In-Scope（本报告重点）

1. 手眼标定、转台回转轴标定、虚拟喷枪 TCP 标定；
2. 扫描视图集设计、多视角点云拼接与融合、网格重建；
3. **拓扑分析**：平面/曲面分割、面片邻接关系（拓扑图）构建、语义归类（顶面/侧面/内腔/薄杆/边棱）；
4. 基于平面先验的**喷涂路径规划**：栅格方向、行距/重叠率、靶距与法向、边缘 Lead-in/Lead-out、面间过渡与喷涂顺序；
5. 路径到关节轨迹的可行性（IK、奇异、碰撞、恒速、时间参数化）；
6. 全流程仿真与**离线可量化验收**（不喷真漆条件下的评价体系）。

### 0.3 本阶段 Out-of-Scope（明确不做，但需预留接口）

- 真实喷枪/供漆系统、气路、雾化参数闭环；
- 漆膜厚度实测与 CFD/沉积模型标定（仅做**解析沉积模型占位**，参数留待工艺标定）；
- 漆雾防护、防爆、通风、废气处理（仅做接口与结构预留）；
- 涂层外观质检（AOI）。

> **一句话结论**：本阶段的成败不取决于路径规划算法有多花哨，而取决于**几何精度链是否闭合**（标定 + 拼接 + 重建 ≤ 允许误差）与**拓扑分割是否稳定可复现**。前者是硬账，后者是工程化的主要人力消耗点。

## 1. 顶层难点：精度链与误差预算（Error Budget）——一切难点的根

这是最容易被忽视、却决定项目生死的部分。前期研究已正确指出"核心风险从算法规划转向系统标定"，本节把它量化。

### 1.1 误差源串联

```
关节零位/减速比误差 ──┐
臂杆 DH 参数误差   ──┤
                     ├─► 法兰位姿误差 ──┐
臂体柔性/负载下垂  ──┘                  │
                                        ├─► 相机测得点在机器人基坐标下的位置误差 ──┐
手眼标定 X 误差 (T_flange→cam) ─────────┘                                          │
                                                                                   ├─► 融合点云/网格误差 ──► 路径几何误差
转台回转轴 位置+方向 标定误差 ──┐                                                  │
转台编码器角度误差/回差       ──┼─► 转台角 θ 对应的 T_base→turntable(θ) 误差 ──────┘
转台端面跳动/轴承游隙         ──┘
                                                                                   
相机深度系统误差 (Z-accuracy, 标定漂移, 温漂) ──────────────────────────────────────┘
相机深度随机噪声 (与距离²、材质、曝光相关)
```

### 1.2 建议误差预算（分配表，可作为验收指标基线）

喷涂对**法向靶距**的敏感度远高于打磨对切向位置的敏感度，但对**切向定位**的容忍度反而更高（漆雾扇面本身有 30–50% 重叠冗余）。因此预算应**各向异性分配**：

| 误差项 | 建议指标 | 理由 |
|---|---|---|
| 全链路法向（靶距方向）误差 | **≤ ±1.5 mm**（3σ） | 典型靶距 150–250 mm，扇面宽度对靶距敏感；±1.5 mm 对应膜厚波动约 1–2% |
| 全链路切向误差 | ≤ ±3 mm | 由重叠率冗余吸收 |
| 表面法向角度误差 | **≤ ±3°** | 法向偏差直接改变沉积椭圆与膜厚分布 |
| 手眼标定 X 残差 | ≤ 0.8 mm / 0.2° | 文献报道基于 3D 视觉的自动手眼标定可达 ~0.93 mm / 0.265°，需通过多姿态优化压到 0.8 mm 以内 |
| 转台轴线方向标定 | **≤ 0.05°** | 关键项：0.1° 轴向偏差在 300 mm 半径处引入 ~0.5 mm 拼接错位，360° 拼接后表现为重影 |
| 转台轴线位置标定 | ≤ 0.3 mm | 同上，直接决定"重影/表面变厚" |
| 转台角度重复定位 | ≤ 0.01° | 需谐波减速 + 绝对编码器；步进+同步带方案难达标 |
| 融合网格与真实几何偏差 | ≤ 1.0 mm RMS（平面区）| 平面先验区可用平面拟合残差直接度量 |

> **攻关要点**：误差预算必须在项目启动第一周就写死并写进测试用例，否则后期"路径抖动"的锅会在视觉、标定、规划、控制四个组之间来回踢。

## 2. 难点域 A：标定攻关（本阶段第一优先级）

### A1. 转台回转轴的高精度标定（**最高风险项**）

**难在哪**：
- 采用运动学拼接（而非纯 ICP）时，点云一致性完全由 `T_base→axis` 的 6 自由度（实际有效 4 自由度：轴线方向 2 + 轴上一点 2）决定。轴线方向误差是**放大型误差**：误差随离轴半径线性放大，家具尺度（R = 300–600 mm）放大系数很大。
- 转台端面并非理想刚体：负载偏心会造成端面跳动与轴倾斜的**载荷相关变化**，即空载标定值在装上 15 kg 椅子后失效。

**攻关路径**：
1. **专用标定件法**：在转台面上固定一个高精度球阵列或棋盘立方体，转台按已知角度序列旋转，相机（机械臂锁死）观测特征点轨迹；每个特征点轨迹应落在垂直于轴线的圆上 → 对所有点的圆拟合做**联合非线性最小二乘**（同时优化轴线方向、轴上点、各点半径），残差即标定精度。
2. **载荷分级标定**：分别在空载 / 中载 / 满载（配重块）下标定，建立轴倾斜随载荷的补偿表；或者机械上直接选用**高刚度轴承 + 大直径回转支承**从源头消除。
3. **运动学 + ICP 混合**：以运动学位姿为初值，做**受约束的位姿图优化（Pose Graph / Bundle Adjustment）**——只允许每帧位姿在运动学预测附近小范围（如 ±1 mm / ±0.2°）微调，并对全局施加"所有帧共享同一回转轴"的硬约束。这样既避免纯 ICP 在对称家具上打滑（转台+圆柱腿几乎旋转对称，纯 ICP 会滑动），又能吸收残余标定误差。**这是本项目推荐的主方案。**
4. **在线自检**：每次上料后用一次快速双视角（0° 与 180°）扫描做一致性检查，重影超阈值即报警要求重标定。

**验收判据**：直径 300 mm 标准平板放在转台边缘，360° 扫描 12 帧融合后，平面拟合厚度（点到最佳拟合平面距离的 P95−P5）≤ 1.0 mm。

### A2. 手眼标定（Eye-in-Hand）

**难在哪**：
- RealSense D4xx 的深度是被动/主动双目立体，标定板在深度图上边界模糊；仅用 RGB 标定得到的外参用于**深度点云**时会有 RGB-Depth 对齐残差（尤其 D435 的 depth-to-color extrinsics 有出厂误差与温漂）。
- 标准 AX=XB 求解（Tsai / Park / Daniilidis）对姿态采样多样性极度敏感，姿态若集中在小锥角内，旋转部分病态。

**攻关路径**：
1. 直接在**深度/点云域**标定：用球标定件（球心可由点云球拟合稳健求出，不依赖边缘），或用 3D 点云配准式手眼标定（LRBO 类方法），避开 RGB→Depth 传递误差。
2. 姿态采样设计：≥ 20 组姿态，姿态间相对旋转角覆盖 > 60°，平移覆盖工作空间三个方向；用**可观测性指标**（旋转轴分布的条件数）在线评估采样是否充分。
3. 与机器人运动学误差**联合辨识**：把 DH 参数偏差（尤其关节零位）与手眼 X 一起放进优化，否则手眼标定会把机器人误差"吸收"成位置相关的错误值。
4. 温漂管理：D4xx 长时间运行 Z 值会漂移，需 15–30 min 预热流程 + 定期在固定标定块上做零点核查。

### A3. 虚拟喷枪 TCP 与工艺坐标系标定

本阶段无真实喷枪，但**必须先定义并标定虚拟 TCP**，否则后期换装喷枪时所有轨迹作废。
- 用工装假枪（与真枪等质量、等重心、等长度的配重体）做 TCP 标定（四点法/六点法），并把**扇面中心轴**定义为 TCP 的 Z 轴。
- 明确扇面的**朝向（扁扇面的长轴方向）**：这是喷涂特有的第 6 自由度约束，路径规划时行进方向必须垂直于扇面长轴，需在 URDF/工艺配置里显式建模，不可留作"随便"。

## 3. 难点域 B：数据采集与视图规划

### B1. 固定高度扫描的盲区问题（前期研究已识别，需量化收口）

**难在哪**：定高平视 + 转台旋转只能覆盖"侧视可见"表面。以下是结构性盲区：
- 桌面/椅面**下侧**（仰角面）；
- 柜体**内壁与隔板上下表面**（深腔遮挡，且深腔内 IR 结构光多次反射→深度噪声爆炸）；
- 顶面在定高平视下入射角接近 90°，深度精度急剧下降（掠射角问题）；
- 腿部之间的**互遮挡**（前腿挡后腿）。

**攻关路径**：
1. 把"定高平视"升级为**分层视图集（Layered View Set）**：每层高度配置 3 种腕部姿态（俯 30°、平 0°、仰 −30°），层数 3–4 层，转台每层 8–12 个分度 → 总帧数 72–144 帧。这是"半结构化"与"覆盖率"的折中。
2. **离线覆盖率验证器（关键工具）**：用工件的名义 CAD 或首件扫描网格，做视线可见性 + 入射角 + 距离窗口（D435 建议 0.2–0.8 m，D455 最小工作距离约 0.5 m，选型需注意）三重判定的**覆盖率仿真**，输出未覆盖面片热力图。视图集设计由这个工具驱动迭代，而非试错。
   > **选型提示**：D455 最小深度距离约 0.5 m，家具近距离扫描空间可能不足；D435/D435i 最小约 0.15 m、近距离精度更优，**近距离桌面级场景优选 D435 系列**。
3. **有限度的补拍（Constrained NBV）**：不做通用 NBV，只做"从预定义候选姿态库中，针对覆盖率热力图的空洞挑选 K 个补拍姿态"。这是可控的、可验证的降级版 NBV，工程风险远低于自由 NBV。
4. 对深腔柜体：接受**分区扫描 + 分区喷涂**的工艺分解，把柜体内腔当独立工件对象处理，必要时要求上料时拆卸门板/抽屉（工艺约束前置，比算法硬扛更划算）。

### B2. 采样同步：Stop-and-Go vs 连续旋转

| 方案 | 优点 | 难点 | 建议 |
|---|---|---|---|
| Stop-and-Go | 无需时间同步，点云清晰，可多帧平均降噪 | 效率低（72 帧 × 1.5 s 驻留 ≈ 2–3 min）；启停震颤 | **第一阶段选此**，并在每个分度点加 200–300 ms 稳定延时 + 5–10 帧时域平均 |
| 连续旋转 | 效率高 | 需 RealSense 深度帧硬件时间戳与转台编码器**共同时基**；D4xx 全局快门有帮助但仍需标定曝光中心时刻偏置；运动模糊 | 二阶段优化项；实现需硬件触发（转台每 N 脉冲触发相机）或 PTP/`ros2` 时间同步 + 时间偏置在线辨识 |

**攻关要点**：即使 Stop-and-Go，也要建立**时间戳→转台角**的插值与延迟辨识流程（标定曝光中心相对触发的固定延迟 τ），否则将来无法平滑升级。

### B3. 材质适应性（RealSense 固有局限，需硬件层解决）

**难在哪**：家具的高反光清漆面、深色/黑色吸光饰面、光滑贴面在双目立体上纹理不足或高光饱和，导致大面积深度空洞与飞点。这不是算法能补救的——**没有数据就是没有数据**。

**攻关路径（按性价比排序）**：
1. **外置结构光投影**：D4xx 支持外部 IR 图案投影仪增强纹理，对无纹理平板效果显著（成本低、见效快，**首选**）。
2. **偏振片 / 交叉偏振**：抑制高光反射（对清漆面有效）。
3. **多曝光 HDR 融合 + 曝光自适应**：depth 侧对不同曝光取有效并集。
4. **降级/替代传感器路线（需在预研期就做对比实验并留决策点）**：若关键工件（黑色哑光板、高光板）覆盖率始终 < 90%，应触发升级到**线激光扫描仪 + 转台**（thin-surface 场景公认更优）或工业结构光相机。**这是必须提前写入方案的技术降级预案。**
5. 前置工艺约束：喷涂前工件多为**素坯/底漆状态**（哑光木色），反光问题其实弱于成品面——应尽早用真实来料做实测，避免过度设计。

**验收判据**：定义"标准件套装"（浅色素坯板、黑色哑光板、高光清漆板、Φ25 圆杆、深 300 mm 柜腔各 1 件），要求各件表面点云**有效覆盖率 ≥ 95%（平面）/ ≥ 85%（圆杆）**，噪声 σ ≤ 0.7 mm @ 0.4 m。

## 4. 难点域 C：重建与拓扑分析

### C1. 多视角融合：重影抑制

见 A1 的混合方案。补充难点：
- **对称性导致的配准歧义**：圆桌面、方凳、四条相同的腿，绕轴 90°/180° 旋转近似自相似，纯几何 ICP 会陷入错误局部极小。→ 必须用运动学先验强约束 + 引入 RGB 颜色/纹理项（Colored ICP）或标定件辅助。
- **点云去噪与飞点剔除**：统计离群点滤波（SOR）参数对细杆结构是**有害**的（细杆本身就是"离群"的稀疏点），需**分区自适应参数**——这是实践中真正耗时间的调参点。

### C2. 薄壁 / 细杆结构的网格化灾难（前期研究已识别，此处给方案）

**难在哪**：Poisson 重建假定封闭定向水密表面，对 Φ15–30 mm 椅腿、栏杆，稀疏噪声点云会产生**粘连（两条腿融成一片）或断裂**；TSDF 在 voxel 尺寸接近壁厚时会出现表面塌陷/自相交（文献明确报告薄件"网格塌陷到模型内部，产生重叠等拓扑错误"）。

**攻关路径**：
1. **结构分类先行，重建策略分治**（推荐主线）：
   - 先做**骨架/初等几何检测**：RANSAC 平面 → 剩余点做圆柱/广义柱体拟合与骨架提取（L1-medial skeleton / Laplacian contraction）；
   - **平面区**：直接用平面拟合 + 边界提取（α-shape / 凹包）生成解析平面片，**不走 Poisson**——这正是"主要面为平面"先验的最大红利，精度和稳健性都远超通用重建；
   - **柱状/细杆区**：拟合为参数化圆柱/扫掠体，用解析几何生成，天然不粘连不断裂；
   - **自由曲面残区**：走 TSDF（voxel ≤ 壁厚/3）或 Screened Poisson，并做**流形性修复**（洞填充、非流形边清理、自相交去除）。
2. **混合模型（Hybrid CAD-ish Model）**：最终输出不是单一网格，而是**"解析基元 + 补丁网格"的混合表示 + 拓扑图**。这对下游喷涂规划极其友好（平面上可直接生成完美等距栅格）。
3. **网格质量门禁（Mesh QA Gate）**：在进入规划前强制检查——是否流形、是否有自相交、法向是否一致朝外、最小面片角、连通分量数是否等于预期部件数。任何一项不合格即**拒绝进入规划**并回退到补拍/参数调整。这个门禁能挡掉绝大部分"轨迹穿过椅腿"的事故。

### C3. 拓扑分析与语义分割（本项目的核心增值点）

**难在哪**：`noether` 提供了基于网格的面分割与刀路生成能力，但它面向的是"一块大曲面做打磨"，而家具是**多部件、多面、有内外之分的装配体**。要得到能驱动喷涂工艺的信息，需要自研一层"拓扑—语义"中间件。

**需要产出的数据结构**：
```
FurnitureTopology
├── Faces[]            # 面片：类型(平面/柱面/自由曲面)、参数、边界环、面积、外法向
├── Adjacency(graph)   # 面-面邻接：共享边、二面角(凸/凹/共面)、边类型(锐棱/圆角/接缝)
├── SemanticLabels     # 顶面/底面/侧立面/内腔面/薄杆/边棱/不喷区(五金件、标签、榫接面)
├── PartClusters       # 部件聚类：桌面、腿×4、横撑、隔板 …
└── Accessibility      # 每面的可达方向锥（由机械臂+转台可达性分析得到）
```

**攻关路径**：
1. **平面提取**：区域生长 + RANSAC 混合，用**法向一致性 + 共面合并**把同一物理面的碎片合并（避免一张桌面被切成 5 个 patch → 5 段互不衔接的路径，这是实际最常见的坑）。
2. **二面角判定与边分类**：凸棱（需 Lead-out 与边缘补偿）、凹角（漆雾堆积区，需降流量/变角度）、共面（应合并）。凹凸判定错误会直接导致喷涂顺序与边缘策略出错。
3. **不喷区（Mask）标注**：小批量家具工艺上必然有不喷区（金属连接件、装配基准面、logo 区）。纯几何无法推断 → 需要**人工标注 GUI + 模板复用**机制（同款家具第二件自动套用首件标注，这是"小批量"场景的关键效率设计）。
4. **可达性分析**：每个面结合 6 轴 + 转台的可达性/碰撞，计算允许的入射方向锥。不可达面必须**在规划前**被识别并上报（提示翻转工件/二次装夹），而不是在轨迹规划失败时才发现。
5. **稳健性 / 可复现性**：同款家具重复扫描，分割结果必须稳定。需建立**分割一致性回归测试**（IoU ≥ 0.95），否则参数一调全盘皆变，无法交付。

## 5. 难点域 D：基于平面先验的喷涂路径规划

### D1. 从"打磨光栅"到"喷涂等距"的算法迁移（前期研究已识别，此处细化）

| 维度 | 打磨/抛光（`noether` 原生场景） | 喷涂（本项目） | 迁移工作量 |
|---|---|---|---|
| 与表面关系 | 接触，贴合每个凹凸 | 非接触，恒定靶距 | 需**TCP 轨迹平滑/偏置层**：先在网格上生成投影点，再沿平滑法向场偏置 standoff，并对轨迹做曲率限幅低通滤波 |
| 行距 | 由砂盘直径与接触宽度决定 | 由**扇面宽度 W(靶距) × (1 − 重叠率 30–50%)** 决定 | 需引入**沉积模型**（β 分布/双高斯椭圆）与行距求解器 |
| 边界 | 到边即停 | 必须**飞出边界** Lead-in/Lead-out（越界距离 ≈ 0.5–1.0 × 扇面宽度）+ 枪控开关点提前/延后 | 需边界外推与"喷枪 On/Off 事件"轨迹标注 |
| 速度 | 允许变速（力控补偿） | **TCP 线速度必须恒定**（膜厚 ∝ 1/v） | 需恒速时间参数化 + 奇异/关节限位规避 |
| 面序 | 无所谓 | 有讲究：先内后外、先难后易、避免漆雾污染已喷面、重力流挂方向 | 需**面序优化（TSP + 工艺约束）** |

**结论**：`noether` 的 `plane_slicer` / raster 类刀路生成器可以复用作**几何骨架**，但喷涂工艺层（standoff、重叠率、lead-in/out、恒速、面序、枪控事件）基本需要自研，约占本阶段规划模块 60–70% 的代码量。切勿在计划里按"直接调用现成库"排期。

### D2. 平面先验带来的简化红利（应最大化利用）

家具"主要面为平面"这个先验是本项目最值钱的条件，必须吃干榨净：
- 平面片上生成路径**无需网格切片**：直接在平面局部 2D 坐标系里对边界多边形做**等距扫描线填充**（含孔洞处理），行距精确、无累积误差、速度极快、结果可解析验证。
- 扫描线方向优选：沿**最长边界方向**扫描以最小化换向次数（换向 = 加减速 = 膜厚异常 + 节拍损失）；同时需与重力方向权衡（水平行进、自上而下推进有利于抑制流挂）。
- 只有**圆角过渡带与自由曲面残区**才需要网格投影法。
- **风险**：真实家具往往有"近似平面"（板材轻微弯曲、贴面起鼓 0.5–2 mm）。平面拟合容差设定过紧 → 一张桌面裂成多片；过松 → 靶距误差超预算。需引入**分级容差 + 拟合残差报告**，容差建议 1.0 mm（对应靶距误差 ≤ 预算的 2/3）。

### D3. 面间过渡与喷涂顺序（易被低估的难点）

- **过渡路径**：面 A 最后一行到面 B 第一行之间，喷枪必须"关枪—抬起—转姿态—落位—开枪"。这段的**姿态插值不能穿过工件**，且要尽量短。本质是一个带碰撞约束的多目标问题。
- **接缝重叠区膜厚**：若转台分度喷涂（转到某角度锁死后喷一面），相邻分度的接缝处必然出现膜厚台阶（前期研究已指出）。缓解手段：接缝处**羽化（Feathering）**——让相邻两次喷涂在接缝带内各承担 50% 流量/半程重叠，需在路径层显式生成"半重叠过渡带"。
- **凹角处理**：两面夹角 < 100° 的内凹处漆雾双重沉积，需要**局部降低重叠率或调整入射角平分线喷涂**。

### D4. 沉积模型（无真实喷漆条件下如何做）

本阶段不喷漆，但路径规划的行距/速度/重叠率必须有模型依据。建议：
1. 采用**参数化解析沉积模型**（椭圆足迹 + β 分布或双高斯径向分布），参数（扇面宽 W、长短轴比、流量分布指数）先取喷枪厂商手册的**名义值**；
2. 实现**膜厚仿真器**：给定路径 + 速度 + 模型，在网格上积分出膜厚场，输出均匀性指标（σ/μ、极值比、覆盖率）。这是本阶段**唯一可信的路径质量量化手段**，必须做，且是验收核心；
3. 把模型参数做成**可标定配置**，未来用真实喷涂的膜厚测量数据反演替换即可，不改上层代码。

## 6. 难点域 E：运动学、联动与轨迹生成

### E1. 7 轴（6 + 转台）联动 vs 分度喷涂

| 方案 | 优点 | 难点 | 建议 |
|---|---|---|---|
| 分度喷涂（转台锁死） | 规划简单，MoveIt 2 原生支持 | 接缝膜厚不均；大件需多次分度导致接缝多；机械臂需大范围伸展，易碰奇异/限位 | **阶段一实现（必须先跑通）** |
| 7 轴联动 | 喷涂连贯、无接缝、可用转台"送料"让机械臂始终工作在灵巧区 | 冗余 IK 需自定义求解器（IKFast 只解析求解 6 轴链；7 轴需数值 IK + 零空间优化或 Tesseract/TrajOpt/Descartes 类笛卡尔规划器）；轨迹平滑与两设备同步插补；实时同步误差 | **阶段二实现**，技术路线：Tesseract + Descartes/TrajOpt 做笛卡尔冗余采样规划，或 MoveIt 2 + 自研 `kinematics_base` 插件（数值 IK + 阻尼最小二乘 + 零空间偏置） |

**攻关要点**：无论哪条路线，**必须在 URDF 里把转台建成运动学链的一环**（`world → turntable_joint → part`），并把工件网格挂在转台坐标系下。若一开始把工件当静态场景物体建模，后期改联动等于重写。这是架构级决策，必须在第一周定下来。

### E2. 奇异点、关节限位与恒速冲突

**难在哪**：喷涂要求 TCP 恒速；接近奇异（尤其 6 轴腕部奇异 J5≈0）时关节速度爆炸，控制器会**自动减速**保护，直接造成该处膜厚超标。这是"路径几何正确但工艺失败"的经典案例。

**攻关路径**：
1. 规划阶段引入**可操作度（Manipulability）/条件数**作为代价，在冗余（转台 + 喷枪绕自身轴的姿态自由度）中寻优避开奇异；
2. 注意喷枪的**扇面长轴方向约束**限制了绕 TCP-Z 的自由度（不像打磨砂盘可自由绕 Z），冗余度实际比想象中少 1 —— 必须显式建模，否则会规划出不可执行的姿态；
3. **速度可行性预检（Pre-flight Check）**：轨迹生成后逐点做 IK 雅可比检查，输出"预测 TCP 速度包络"，标记所有速度跌落 > 5% 的区段并要求重规划。这个检查器价值极高，成本很低。

### E3. 时间参数化与轨迹平滑

- 需要**恒速段 + 端部加减速**的定制时间参数化（TOTG/Ruckig 类工具默认追求最短时间，会在拐角自动降速 → 膜厚异常）。正确做法是：把加减速全部安排在工件**边界之外**（Lead-in/out 区间内），保证工件上方全程严格恒速。
- 轨迹点密度与控制器插值周期匹配；点太密会撑爆控制器缓冲，太疏会导致弦误差超差。
- 关节层需限制 jerk，避免机械振动传导到相机/喷枪。

## 7. 难点域 F：软件工程与系统集成（隐性但吞噬工期）

1. **依赖地狱**：`noether` 历史上依赖定制版 PCL / VTK，`scan_n_plan_workshop` 依赖 Tesseract 生态。ROS 2 发行版 + Tesseract + PCL/VTK/Open3D 的版本组合是真实的、常被低估的成本。→ 必须**容器化（Docker）+ 锁定版本 + CI 构建**，第一周就做。
2. **框架适配 vs 自研的边界**：`scan_n_plan_workshop` 是"感知驱动的表面处理"通用框架（其官方 demo 即为机械臂 + RealSense 重建工件后规划抛光轨迹），架构可直接复用，但每一层都需替换/扩展。要在方案里明确"复用骨架、替换工艺层"，避免团队产生"开源现成"的错误预期。
3. **数据与配置管理**：小批量场景意味着**款型多、批量小**。必须有"工件档案库"：首件的标注、分割参数、路径模板、验收报告全部入库并可一键复用到同款次件。**这是小批量经济性的命门，比算法先进性更影响商业成败**，但常被排在最后做。
4. **可视化与人工干预（HMI）**：小批量不可能全自动零干预。必须提供：分割结果可视化与手动改正、不喷区刷选、路径预览与逐段回放、膜厚仿真热力图、一键重规划。**HMI 是交付物而非附属品**，工作量约占前端 1 个人力全周期。
5. **仿真环境**：在无真机/无漆条件下，仿真是唯一开发载体。需要 Gazebo/Isaac 或 Tesseract 的可视化 + 虚拟 RealSense（可用 CAD 模型渲染合成深度图 + 加噪模型），以便在硬件到位前跑通全链路并生成回归测试集。

## 8. 验收体系：不喷真漆如何证明"路径规划做对了"

这是本阶段方案评审最容易被追问、也最需要提前设计的部分。建议五级验收：

| 级别 | 验收内容 | 手段 | 指标 |
|---|---|---|---|
| L1 几何 | 标定与重建精度 | 标准球杆/标准平板 + 三坐标或激光跟踪仪对比 | 见 §1.2 误差预算表 |
| L2 拓扑 | 分割正确性与可复现性 | 人工标注 GT + 重复扫描 | 面分割 IoU ≥ 0.95；部件数正确率 100%；重复性 IoU ≥ 0.95 |
| L3 路径几何 | 覆盖率、靶距、法向、行距 | 离线路径分析器 | 待喷面覆盖率 ≥ 99.5%；靶距误差 ≤ ±1.5 mm；法向误差 ≤ ±3°；行距误差 ≤ ±5% |
| L4 工艺仿真 | 膜厚均匀性 | 自研膜厚仿真器（§5.4） | 膜厚 σ/μ ≤ 10%（平面区）；边缘 20 mm 带内不低于均值 80% |
| L5 运动执行 | 可执行性与恒速性 | 真机空跑（不喷漆）+ 关节反馈记录 | 无碰撞、无奇异告警；工件上方 TCP 速度波动 ≤ ±3%；节拍达标 |

> **额外建议**：用**水性显影液/粉笔粉喷雾**或**贴纸+激光笔打点**做低成本物理验证；更直接的办法是用**水喷/压缩空气 + 感温纸/水敏纸**做覆盖验证，成本极低却能真实暴露盲区与接缝问题。这属于 L4.5，强烈建议加入。

## 10. 攻关路线图（建议 6 个里程碑，约 9–11 个月）

| 里程碑 | 周期 | 交付物 | 通过判据（Gate） |
|---|---|---|---|
| **M0 基座** | 第 1–4 周 | Docker/CI、含转台关节的完整 URDF、仿真场景、虚拟相机、标准件套装、误差预算文档 | 全链路空跑可在仿真中跑通；误差预算评审通过 |
| **M1 精度闭环**（**最关键**） | 第 5–14 周 | 手眼标定、转台轴标定、约束位姿图融合、上料自检 | 标准平板 360° 融合厚度 ≤ 1.0 mm；标准件全套通过 L1 |
| **M2 重建与拓扑** | 第 12–24 周 | 分治重建（平面/柱面/自由曲面）、网格 QA 门禁、拓扑图 + 语义分割、标注 HMI | 3 类样件（桌/椅/柜）通过 L2；重复性 IoU ≥ 0.95 |
| **M3 路径规划** | 第 20–34 周 | 平面等距填充、standoff 偏置与平滑、行距/重叠率求解、Lead-in/out、面序优化、膜厚仿真器 | 通过 L3 + L4；仿真膜厚 σ/μ ≤ 10% |
| **M4 运动执行（分度）** | 第 30–40 周 | 分度喷涂轨迹生成、碰撞检查、恒速时间参数化、速度可行性预检、真机空跑 | 通过 L5；水敏纸物理验证覆盖率达标 |
| **M5 联动与产线化** | 第 38–46 周 | 7 轴联动规划、接缝羽化、工件档案库、完整 HMI、节拍优化 | 单件节拍达标；换款上线时间 ≤ 目标值（如 ≤ 30 min） |

> M1 是唯一不可压缩的里程碑。前期研究的判断值得重复：**只要 360° 旋转得到的点云能严丝合缝拼成一张无重影的完整点云，项目前半段就成功了 80%。** 建议把 M1 设为强制 Gate，未通过不得启动 M3。

## 11. 关键决策点（需在立项评审前明确）

1. **相机型号**：D435/D435i（近距离精度优、最小 0.15 m）vs D455（远距精度优、最小约 0.5 m）。家具桌面级场景倾向 **D435i**，并预留线激光升级位。
2. **转台传动**：谐波减速 + 绝对编码器（推荐，可达 0.01° 重复定位）vs 步进 + 同步带（成本低但精度与回差风险高）。
3. **运动规划栈**：MoveIt 2（生态成熟、7 轴需自研 IK 插件）vs Tesseract/Descartes（笛卡尔冗余规划原生更强、与 `scan_n_plan_workshop` 同源）。**建议 Tesseract 主线**，因其与所选框架同源且笛卡尔约束能力更契合喷涂。
4. **联动策略**：是否在本阶段就承诺 7 轴联动，或将其列为 M5 可选项。
5. **是否引入外置 IR 投影/偏振**：建议在 M0 阶段就做 2 周对比实验后定案，成本远低于后期返工。

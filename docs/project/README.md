# 项目资料

本目录保存不参与程序运行的项目资料。它们用于说明团队分工、技术难点和阶段方案，与代码入口分开管理。

| 文件 | 内容 | 使用时机 |
| --- | --- | --- |
| [`人员分工与团队规划.md`](人员分工与团队规划.md) | 团队角色、任务边界和推进计划 | 讨论分工和交付责任 |
| [`技术重难点分析报告.md`](技术重难点分析报告.md) | 相机、重建、配准和喷涂链路的技术风险 | 评审方案和排查瓶颈 |
| 对应 `.pdf` | 以上资料的固定版输出 | 对外汇报或打印 |

资料不是运行入口。运行仿真、真机或 ROS 2 工程时，应回到根目录 README 的项目导航。

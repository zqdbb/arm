# 8 台 Gemini 335L 的 ChArUco 位姿标定方法

本文给出一套面向本项目 8 台固定 Gemini 335L 的实机标定方法。目标是获得每台相机在同一米制世界坐标系下的位姿，并导出 Open3D TSDF 可直接使用的 `world_to_camera` 矩阵。

ChArUco 可以完成全部相机的统一外参标定，但前提不是“每台相机各自拍到标定板”，而是所有相机通过同一静止板位姿的共同观测形成一个连通的标定网络。若两组相机从未在同一板位姿下看见标定板，且标定板移动位姿也未知，则仅凭这些图像不能求出两组相机之间的相对位姿。

## 1. 标定输出

每台相机至少保存以下信息：

- 设备序列号与固定名称 `cam01` 至 `cam08` 的对应关系。
- 实际采集分辨率下的内参 `fx, fy, cx, cy`。
- 畸变模型和畸变系数。
- 深度比例 `depth_scale`。
- 彩色、左/右红外和深度光学坐标系之间的设备内部外参变换。
- `camera_to_world`：相机光学坐标到世界坐标的 4×4 矩阵。
- `world_to_camera`：世界坐标到相机光学坐标的 4×4 矩阵。

本项目和 OpenCV 使用的光学坐标约定一致：`X` 向右、`Y` 向下、`Z` 向前。Open3D TSDF 的 `integrate()` 需要 `world_to_camera`：

```text
p_camera = T_camera_world @ p_world
T_camera_world = inverse(T_world_camera)
```

在上述记号中，`world_to_camera` 等价于 `T_camera_world`，`camera_to_world` 等价于 `T_world_camera`；下标顺序表示输出坐标系和输入坐标系。

矩阵的平移统一使用米。不得把毫米平移直接写入 TSDF 外参。

## 2. 标定板建议

当前布局中相机到车辆区域约为 3–5 m，A4 或 A3 标定板通常太小。建议采用：

| 项目 | 建议值 |
| --- | --- |
| 板型 | ChArUco，`5×7` 或 `6×8` 方格 |
| ArUco 字典 | `DICT_5X5_1000` |
| 方格边长 | 160–200 mm |
| Marker 边长 | 方格边长的 70%–78% |
| 板面尺寸 | 约 0.8–1.4 m，按实际方格数确定 |
| 基板 | 铝塑板、蜂窝板或其他不易弯曲的哑光刚性板 |

例如 `5×7`、方格 180 mm 时，图案尺寸约为 0.9×1.26 m。最终计算必须使用成品实测尺寸，不能只使用打印文件中的设计尺寸。建议用钢尺或卡尺测量多个横向、纵向方格，检查打印缩放和长宽方向是否一致。

标定板应满足：

- 平面不翘曲，移动过程中不弯折。
- 表面哑光，避免顶灯和红外照明造成高光。
- 四周保留白边，不能裁掉最外层方格。
- 记录 `squares_x`、`squares_y`、`square_length_m`、`marker_length_m` 和字典名称。
- Marker ID、方格参数和程序中的 `CharucoBoard` 定义完全一致。

标定板上单个 Marker 最好至少有约 20–30 像素宽。可用下式粗略估算：

```text
marker_pixels ~= fx_pixels * marker_size_m / distance_m
```

若 Marker 太小，应增大标定板、缩短距离或使用更高采集分辨率，而不是依赖图像放大。

## 3. 标定前固定系统状态

1. 将 8 台相机机械固定并锁紧；完成外参标定后不能再移动支架、镜头或相机。
2. 固定实际运行时的分辨率、帧率、深度模式和 RGB-D 对齐模式。
3. 记录 8 台设备序列号，禁止依赖 USB 枚举顺序命名相机。
4. 相机预热至少 15–20 分钟，再开始采集。
5. 固定曝光、增益和白平衡；至少在一轮标定中不要让参数不断变化。
6. 移走车辆和其他大面积遮挡物，使相邻相机能共同看到标定板。
7. 启用硬件同步，或保证每组图片中的标定板完全静止后再依次触发。

标定时使用真实设备 EEPROM/SDK 返回的参数。规格书中的典型内参只能用于仿真，不能替代 8 台实机的逐台参数。

## 4. 相机内参与 RGB-D 坐标关系

### 4.1 内参

优先先从 Orbbec SDK 读取每台设备在目标分辨率和工作模式下的出厂内参、畸变和深度比例，再用 ChArUco 重投影误差做验证。若需要重新优化内参，每台相机单独采集 30–50 组图像，覆盖图像中心、四角、边缘、远近距离和不同倾角。

内参标定不能只在图像中心正对标定板。图像边缘缺少观测时，畸变参数容易不稳定。

### 4.2 ChArUco 求得的是哪个相机位姿

若在 RGB 图像中检测 ChArUco，求得的是彩色光学相机位姿，不是原生深度光学相机位姿。真实重建有两种处理方式：

1. 深度已由 SDK 对齐到彩色图：使用彩色相机内参和 `world_to_color`，把对齐后的深度视为彩色光学坐标中的深度。
2. 使用原生深度图：必须使用原生深度内参，并通过设备的 `depth_to_color` 外参把 ChArUco 标定结果转换到深度光学坐标。

定义 `T_A_B` 为“把 B 坐标转换到 A 坐标”。如果 SDK 给出 `T_color_depth`，即深度坐标到彩色坐标的变换，则：

```text
T_world_depth = T_world_color @ T_color_depth
T_depth_world = inverse(T_world_depth)
```

最终应在标定文件中明确矩阵对应 `color_optical_frame` 还是 `depth_optical_frame`，不能只写含义不明的 `extrinsic`。

Open3D 的针孔投影不会自动处理镜头畸变。积分前应先去畸变，或使用 SDK 输出的已校正/已对齐图像，同时使用校正后对应的内参。

## 5. 八相机采集拓扑

本项目的相机编号为上层 `cam01`–`cam04`、下层 `cam05`–`cam08`。推荐至少覆盖以下共同观测边：

```text
上层环：01-02, 02-03, 03-04, 04-01
下层环：05-06, 06-07, 07-08, 08-05
上下层：01-05, 02-06, 03-07, 04-08
```

尽量再增加对角共同观测，例如 `01-06`、`02-07`、`03-08`、`04-05`。环路约束可用于发现某一对相机的错误结果，并减少沿单链传播造成的累积漂移。

每条相邻边建议获得 10–20 组有效共同观测。一次有效观测必须满足：

- 两台或更多相机在同一板位姿下拍摄。
- 每台相机至少检测到 6–10 个 ChArUco 角点，越多越好。
- 标定板占图像约 10%–35%，不是远处的小块区域。
- 包含正面、左右倾斜、上下倾斜和不同高度，而不是所有图像都平行正对。
- 角点清晰，无运动模糊、过曝、反光和严重遮挡。

移动顺序可按“上层环 → 下层环 → 四组上下层 → 对角补强”进行。每到一个位置先保持标定板静止，再采集一个带统一时间戳或组号的 8 相机图像集合。无法看到板的相机可以在该组为空。

采集记录至少包含：

```text
calibration_capture/
├── board.json
├── device_parameters/
│   ├── cam01.json
│   └── ...
├── group_0001/
│   ├── cam01.png
│   ├── cam02.png
│   └── capture.json
└── ...
```

如果相机视场之间完全没有共同区域，单块自由移动的 ChArUco 板无法完成统一标定。此时需要增大或使用双面刚性标定板、增加中继相机、使用已知几何关系的多板刚性标定架，或用全站仪/机械测量提供额外约束。

## 6. 外参求解

### 6.1 单次观测初值

对每张图执行：

1. 检测 ArUco Marker。
2. 插值 ChArUco 角点并执行亚像素优化。
3. 用真实内参和畸变参数执行 PnP，得到该组标定板到相机的 `T_camera_board`。
4. 删除角点数不足、重投影误差过大或几何条件差的观测。

对于同一时刻共同看到板的相机 `i` 和 `j`：

```text
T_cam_j_cam_i = T_cam_j_board @ inverse(T_cam_i_board)
```

这可生成相机图的边和全局优化初值。不要直接平均旋转矩阵；旋转应在 SO(3) 或 SE(3) 上优化。

### 6.2 全局联合优化

最终结果应使用全局 Bundle Adjustment，而不是只把相邻相机变换沿一条链相乘。联合优化变量包括：

- 8 台固定相机的世界位姿。
- 每个采集组中标定板的世界位姿。
- 可选的内参微调；首轮建议先固定 SDK 或单目标定得到的内参。

优化目标是所有已检测 ChArUco 角点的重投影误差，并使用 Huber 或 Cauchy 鲁棒核降低误检影响。固定 `cam01` 位姿或一个参考板位姿以消除整体自由度，优化后再将结果对齐到现场世界坐标。

建议分两轮求解：

1. 初次优化后删除重投影残差明显异常的角点和整组观测。
2. 用清理后的数据重新优化，并输出每台相机、每条共同观测边和整体误差统计。

## 7. 建立车辆工位世界坐标系

只固定 `cam01` 为原点可以完成多相机拼接，但这个坐标系不一定符合项目定义的车辆世界坐标：`+X` 朝车头、`+Y` 朝车辆左侧、`+Z` 向上。

推荐在空工位中设置一个可重复定位的基准：

- 标定板固定在已测量的工装定位孔或地面基准点上。
- 用水平仪确定板面或基准边与重力方向的关系。
- 测量板坐标原点到车辆工位原点的刚体变换。
- 将标定得到的相机网络整体左乘该刚体变换，得到 `T_world_camera_i`。

若直接将某一次标定板坐标定义为世界坐标，必须保存该次板的安装方向、原点定义和定位治具；否则重新标定后世界坐标会发生不可控变化。

## 8. 导出格式

建议导出一个版本化 JSON，并保留标定时间、设备序列号、图像模式和误差报告：

```json
{
  "schema_version": 1,
  "length_unit": "meter",
  "optical_convention": "x_right_y_down_z_forward",
  "extrinsic_convention": "world_to_camera",
  "board": {
    "dictionary": "DICT_5X5_1000",
    "squares_x": 5,
    "squares_y": 7,
    "square_length_m": 0.18,
    "marker_length_m": 0.135
  },
  "cameras": [
    {
      "name": "cam01",
      "serial_number": "REPLACE_WITH_DEVICE_SERIAL",
      "frame": "color_optical_frame",
      "width": 1280,
      "height": 800,
      "intrinsics": {
        "fx": 0.0,
        "fy": 0.0,
        "cx": 0.0,
        "cy": 0.0
      },
      "distortion_model": "REPLACE_WITH_SDK_MODEL",
      "distortion_coefficients": [],

        [1.0, 0.0, 0.0, 0.0],
```

## 9. 验收方法

不要只看重投影误差。至少进行以下四类验收：

### 9.1 重投影误差

- 输出整体、逐相机和逐采集组的 RMS、均值和 P95。
- 清晰图像下可把整体 RMS 小于 0.5 px 作为目标。
- 0.5–0.8 px 应检查边缘图像、板尺寸、内参和同步。
- 大于 0.8 px 通常不应直接用于高精度 TSDF，应先定位异常观测。

阈值不是设备保证值；远距离、小 Marker 或低照度环境可能需要重新设计标定板和采集距离。

### 9.2 环路闭合

计算上层环、下层环和上下层环路的闭合误差。理论上沿环路累乘相对变换应回到单位矩阵。明显的闭合平移或旋转误差通常表示某条边存在误检、时间不同步或视角退化。

### 9.3 独立测试图像

另采集一批不参与求解的 ChArUco 图像，使用最终外参预测角点并统计误差。只报告训练图像残差不能证明标定具有泛化能力。

### 9.4 深度点云和实物尺寸

在相邻相机重叠区放置刚性平面和已知尺寸标准件：

- 将各相机点云变换到世界坐标，检查平面是否出现双层或扇形发散。
- 统计重叠点云的点到平面、点到点或点到 Mesh 距离。
- 测量标准件长度、宽度和高度，检查米制尺度。
- 用独立场景完成一次 8 相机 TSDF，检查接缝、重影和边缘厚度。

旋转误差在远距离会被放大：约 `0.1°` 的角度误差在 4 m 处可产生约 7 mm 横向偏差。因此本项目若希望多视角接缝控制在约 1 cm 内，应把外参重复性目标设为平移约 3–5 mm、旋转约 0.05°–0.1°，同时满足相机本身的深度精度和同步条件。这是系统目标，不是 ChArUco 单独能够保证的指标。

## 10. 推荐验收清单

- [ ] 8 台设备序列号和 `cam01`–`cam08` 映射固定。
- [ ] 标定分辨率、帧率、深度模式与生产运行一致。
- [ ] 使用成品实测的方格和 Marker 米制尺寸。
- [ ] 相机共同观测图是连通图，并含多个闭合环路。
- [ ] 每条主要相邻边有 10–20 组有效共同观测。
- [ ] 使用全局联合优化，而不是只做单链变换累乘。
- [ ] 输出矩阵明确区分 `camera_to_world` 与 `world_to_camera`。
- [ ] 输出矩阵明确对应彩色还是深度光学坐标系。
- [ ] 图像已按对应内参去畸变或由 SDK 校正。
- [ ] 独立图像、环路闭合、重叠点云和标准件尺寸均通过验收。
- [ ] 标定结果和相机支架状态有版本号、日期及备份。

## 11. 常见失败原因

| 现象 | 常见原因 |
| --- | --- |
| 两组相机无法统一 | 共同观测图不连通，或不同时间的板位姿被误当成同一位姿 |
| TSDF 出现多层重影 | 外参方向取反、毫米/米混用、RGB-D 未对齐或不同步 |
| 上层和下层点云分离 | 缺少上下层共同观测边，只有两个独立环 |
| 中心对齐、边缘发散 | 旋转外参误差、畸变未校正或内参分辨率不匹配 |
| 单目标定很好，多相机仍错 | 使用了彩色位姿处理原生深度，或设备内部 depth-color 外参方向错误 |
| 重复标定结果漂移大 | 标定板弯曲、支架松动、Marker 太小、采集姿态单一或曝光不稳定 |
| 误差很小但真实尺寸错误 | 标定板打印缩放不准，或深度比例配置错误 |

完成标定后，应先用独立标准件和重叠点云验证，再把矩阵接入整车 TSDF。ChArUco 的低重投影误差只是必要条件，不等于深度融合一定准确。
